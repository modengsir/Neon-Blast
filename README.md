# Neon Blast · 方块爆破

一个打开浏览器就能玩的 3D 网页小游戏。固定 11×11 地图、90 秒倒计时、两个机器人敌人，无后端、无需账号，不调用模型 API。

## 在线试玩

### [▶ 点击开始 Neon Blast](https://modengsir.github.io/Neon-Blast/)

使用电脑浏览器打开，无需下载、安装或注册。WASD / 方向键移动，空格放炸弹。点击“开始挑战”后播放声音。

网页由 GitHub Pages 免费托管；推送到 `main` 分支后会自动更新。

## 本地运行

Mac 双击 `start.command`，保留启动的终端窗口，再访问 http://localhost:8765 。需要 Python 3（本机已安装）。如果系统不允许双击脚本，在项目文件夹打开终端运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

然后在浏览器打开 http://localhost:8765 。关闭服务器使用 Ctrl+C。不要直接双击 index.html，浏览器会限制本地 ES 模块加载。如果端口被占用，可以将命令中的 8765 改为 8766，并访问对应地址。

## 操作与规则

- WASD / 方向键：按格移动；空格：放炸弹；P / Esc：暂停或继续。
- 最多同时放置 3 颗炸弹；2 秒引信、十字方向 3 格爆炸，火焰持续约半秒。
- 墙体挡住爆炸；木箱被炸后阻挡本次火焰；炸弹可连锁引爆。
- 木箱 +50 分，机器人 +500 分；通关每剩余 1 秒奖励 10 分。
- 爆炸及接触敌人都会失败。消灭两个敌人后，走到右下角出口获胜。
- 页面离开焦点时自动暂停，右上角可关闭震动。

起步提示：从出生点向右走一格放炸弹，立即左移再下移，躲到墙后。爆炸结束后再进入通道。多颗炸弹可封住机器人的退路。

## 文件

`engine.mjs` 游戏规则和 BFS 寻路；`main.js` Three.js 场景、输入及界面；`style.css` 样式。模型由原创几何体组合构建，所有运行资源已包含在项目中，无需 npm 安装或联网。Three.js 采用 MIT 许可，见 vendor/LICENSE。

## 验证

使用 Node.js 执行 `node test.mjs`，检查碰撞、暂停、炸弹去重、墙体与箱子阻挡、连锁反应、自伤、敌人消灭、出口胜利、超时、重置与 AI 避险。浏览器另行检查真实 WebGL 渲染与键盘操作。

内置原创合成器背景音乐（112 BPM），开始或继续游戏时播放，暂停、切换窗口和游戏结束时停止；右上角“声音”按钮可同时开关音乐与全部音效。声音在本地生成，无需下载音频。

此版为桌面键盘 MVP，没有触屏控制、关卡选择或联网功能。

音效覆盖：玩家脚步、轻声敌人脚步、放弹、逐渐加快的引信提示、爆炸、木箱碎裂、敌人击败、出口开启、最后十秒提示、开始/重开、按钮、胜利与失败。暂停或失焦会停止当前音效；连锁爆炸做限幅和同帧合并，避免声音叠加过响。全部由本地 Web Audio 合成。
